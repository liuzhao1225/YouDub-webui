# YouDub UI 设计规范 v1.0

2026-10-22 · 适用：桌面应用、业务页面、插件提供的产品界面。

本规范从现有 Logo、主题代码、桌面外壳及工作台、任务、字幕校对、播放器、环境准备截图提取。**现有基线** 表示当前资产或实现；**统一标准** 表示后续设计与开发执行的规则。规范完成不代表全产品已完成视觉整改。

[打开明暗主题视觉速查页](ui-design-reference.html)。速查页展示规范示例，不连接真实任务或下载状态。

## 1. 品牌定位与视觉性格

**品牌定义：亲和、清晰、可掌控的视频语言工作台。**

| 特征 | 视觉表达 | 行为表达 |
| --- | --- | --- |
| 视频与声音 | 现有播放气泡、左右声波、媒体画面 | 播放、定位、试听和导出入口清楚 |
| 轻盈与亲和 | 柔和圆角、低饱和底色、少量粉蓝渐变 | 用具体动作命名，减少技术术语 |
| 专注与专业 | 字幕对齐、稳定栅格、紧凑列表 | 优先呈现内容、结果与必要参数 |
| 可掌控 | 状态标签、真实进度、清晰的当前项 | 错误可见，修改可保存，日志可展开 |

品牌色集中在 Logo、主操作、选中标记和少量状态提示。大面积使用中性色。视频、字幕和音频结果拥有最高内容优先级。

现有“让视频说另一种语言”保留为工作台入口的品牌表达；任务、设置、资源、日志页面不重复口号。品牌氛围光只用于入口区域，内容编辑区保持平静背景。

## 2. Logo 与品牌资产

**现有基线：** 红色播放气泡，左侧粉色声波，右侧蓝色声波；字标沿用现有 YouDub 资产与粉蓝渐变。[资产](../../apps/web/public/youdub-logo.svg) · [图形标](../../apps/web/public/youdub-icon.svg) · [品牌组件](../../apps/web/src/components/brand/brand-mark.tsx)。

统一标准：

- 使用原 SVG 等比缩放；完整字标与独立图形标分别用于宽侧栏和紧凑入口。
- Logo 四周留白至少为其显示高度的 1/4；高度按容器确定，侧栏建议 28–32px，紧凑图形标 24px。
- 使用原资产中的字形；不以普通字体重新拼写字标，不修改三角、声波和气泡比例。
- 粉→蓝渐变方向固定为从左向右；垂直选中标记可从上向下。
- 声波动画仅用于品牌入口或明确的运行态；遵循系统减少动态效果设置。
- 窗口系统指示器、鼠标高亮和截图标注不属于 YouDub 品牌资产。

## 3. 颜色与语义

### 3.1 品牌原色：保留

| Token | 值 | 使用范围 |
| --- | --- | --- |
| `brand-red` | `#FF0033` | Logo、品牌图形、装饰性强调 |
| `brand-pink` | `#FB7299` | 声波、渐变起点、运行态底色 |
| `brand-blue` | `#00AEEC` | 声波、渐变终点、完成态底色 |

渐变遵循 `brand-pink → brand-blue`。不把渐变作为长段文字、输入内容、错误信息的填色。

### 3.2 中性色：现有主题基线

| 语义 / 现有 Token | 浅色 | 深色 | 规则 |
| --- | --- | --- | --- |
| 页面 `background` | `#F6F6F8` | `#0A0A0E` | 承载整页 |
| 外壳 `surface` | `#FBFBFC` | `#0E0E13` | 侧栏与次级区域；平台透明材质允许感知色差 |
| 内容 `card` | `#FFFFFF` | `#121218` | 内容组、编辑区域 |
| 浮层 `elevated` / `popover` | `#FFFFFF` | `#18181F` | 菜单与对话框 |
| 主文字 `foreground` | `#0B0B0F` | `#EDEDF0` | 标题、正文、可操作图标 |
| 次文字 `muted-foreground` | `#5F5F6B` | `#A0A0AB` | 元数据、单位、必要提示 |
| 分隔 `border` | `rgb(9 9 11 / 8%)` | `rgb(255 255 255 / 8%)` | 组内分隔；不单独承担控件识别 |

### 3.3 功能色：统一目标

| 用途 | 浅色 | 深色 | 对现状的要求 |
| --- | --- | --- | --- |
| 主按钮底色 `primary` | `#E6002E` | `#E6002E` | 现状为 `#FF0033`，待收敛 |
| 主按钮悬停 `primary-hover` | `#CC0029` | `#CC0029` | 保持白字可读 |
| 主按钮文字 | `#FFFFFF` | `#FFFFFF` | 固定白色 |
| 链接 `link` | `#00739F` | `#3CC4F5` | 保留，正文链接增加下划线或明确的链接结构 |
| 完成 `status-success-fg` | `#00739F` | `#5FD0F5` | 保留蓝色完成态，配勾选及“已完成” |
| 运行 `status-running-fg` | `#C2185B` | `#FF9AB8` | 配“下载中 / 安装中 / 处理中” |
| 待确认 / 警告 | `#9A5B00` | `#F7C26B` | 配具体标签，不能只改变颜色 |
| 错误 / 危险操作 | `#C8002A` | `#FF6B81` | 配错误原因或明确的删除动作 |
| 占位与辅助文字 | `muted-foreground` | `muted-foreground` | 当前 `subtle-foreground` 仅限非必要装饰 |
| 输入轮廓 `input` | `#DEDEE3` | `#383840` | 沿用 Harness 的细边线；输入与上传区使用干净表面色 |
| 焦点指示 | `#00739F` | `#3CC4F5` | 沿用 Harness 原生焦点样式；输入控件不额外叠加蓝色外圈 |

完成态采用品牌蓝是既有产品语义。主操作的红色与错误红通过结构区分：主操作为实心按钮；错误为带图标的文本/提示区；删除默认使用低强调危险按钮，确认动作明确写“删除任务”。

### 3.4 可读性依据

按 [W3C 文本对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)，普通文本采用至少 4.5:1，大文字至少 3:1；必要控件标识和状态指示采用至少 3:1，见 [W3C 非文本对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。轻分隔线可保持低对比，关键识别信息须由可读文字、图标或足够清晰的轮廓承担。

当前 CSS 纯色计算结果如下；最终验收还需检查透明叠加后的实际背景。

| 组合 | 比值约值 | 设计结论 |
| --- | --- | --- |
| 白字 / 现有红 `#FF0033` | 3.96:1 | 小字号主按钮需要收敛 |
| 白字 / 目标红 `#E6002E` | 4.77:1 | 适合普通按钮文字 |
| 浅色辅助灰 `#8B8B96` / 白底 | 3.37:1 | 不用于必要提示、占位文字 |
| 深色辅助灰 `#7A7A86` / `#121218` | 4.40:1 | 同上，不能按四舍五入视为通过 |
| 浅色链接 `#00739F` / 白底 | 5.31:1 | 保留 |
| 品牌蓝 `#00AEEC` / 白底 | 2.54:1 | 限品牌装饰；功能图标使用链接色 |

## 4. 字体、排版与数字

界面沿用系统无衬线字体。中文优先系统中文字体，英文与数字使用系统 UI 字体。日志使用系统等宽字体；时间、大小、速度使用等宽数字 `tabular-nums`，不把整个表单改成等宽字。

| 层级 | 字号 / 行高 | 字重 | 应用 |
| --- | --- | --- | --- |
| 品牌展示 | `clamp(28px, 4vw, 48px)` / 1.2 | 700 | 工作台现有品牌标题，限入口 |
| 页面标题 | 24 / 32px | 600 | 任务、资源、设置、节点标题 |
| 分组标题 | 16 / 24px | 600 | 生成文件、输入参数 |
| 正文与标准控件 | 14 / 20px | 400 / 500 | 字幕、译文、按钮、表单 |
| 辅助信息 | 12 / 18px | 400 | 单位、时间、格式、版本 |
| 日志 | 12 / 18px | 400 | 保留换行，长行可折行 |

正文不使用 300 细字。14px 正文优先保证行距；长字幕自然换行，不以固定高度截断可编辑内容。窄屏可输入控件使用 16px 字体，避免部分移动浏览器聚焦时放大。

## 5. 间距、圆角与层次

### 5.1 间距系统

采用 **4px 基础刻度、8px 主节奏**。允许值：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px。

| 关系 | 标准 |
| --- | --- |
| 图标与短文字 | 8px；紧凑控件 4px |
| 标签到输入框 | 8px |
| 同组操作间距 | 8px |
| 列表行内边距 | 12px |
| 普通卡片内边距 | 16px |
| 对话框 / 主输入组内边距 | 24px；窄屏 16px |
| 同页内容组间距 | 24px |
| 桌面内容边距 | 上下 24px，左右 32px |
| 窄屏内容边距 | 16px |

输入框和上传区域的默认边界保持轻盈，避免深灰描边与大面积灰色填充叠加；聚焦、拖入和错误状态才增强边界。品牌标题、背景氛围和整体布局保留。

宽度由共同父容器和栅格决定。同组视频链接框与上传区左右边缘完全一致。表头、列表行、底部操作共享内容边界。避免单个控件额外加 padding 修补截图对齐。

### 5.2 圆角：收敛到四档

| 目标 Token | 值 | 应用 |
| --- | --- | --- |
| `radius-control` | Harness `radius-md`（12px） | 按钮、输入框；紧凑按钮和多行编辑器使用 `radius-sm`（8px） |
| `radius-panel` | Harness `radius-lg`（16px） | 内容组；菜单直接复用 Harness Menu 的圆角 |
| `radius-dialog` | Harness `radius-panel`（28px） | 对话框直接复用 Harness Modal |
| `radius-pill` | 999px | 状态标签、轨道滑块 |

Harness 已有的基础控件直接使用其组件、尺寸、圆角和状态样式。YouDub 只负责布局与品牌主题映射，页面不覆盖控件外观。相同功能使用同一组件；多行表单复用 Harness 编辑器样式并保留原有保存语义。

### 5.3 层次

- 页面 → 内容组 → 行。列表用一个容器加细分隔，行内不继续套卡片。
- 卡片默认依赖底色与轻边框；普通列表和底部操作条不加浮层阴影。
- 菜单、弹窗直接复用 Harness 的阴影和层级，不叠加 YouDub 阴影。
- 单个内容组避免同时叠加强边框、渐变描边、厚阴影和玻璃效果。
- 玻璃材质限桌面外壳与悬浮操作；编辑正文保持稳定底色。

## 6. 组件与交互

### 6.1 控件尺寸与状态

| 组件场景 | 高度 / 点击区域 | 图标 | 说明 |
| --- | --- | --- | --- |
| 紧凑按钮 | Harness 28px | 16px | 普通控件使用 Harness 默认档位 |
| 标准按钮 | 36px | 16px | 保存、刷新、页内动作 |
| 普通输入框 | Harness 32px | 16px | 下拉入口使用 Harness Button + Menu |
| 工作台主动作 | 44px | 20px | 开始处理 |
| 触屏交互目标 | 至少 44×44px | 20px | 图标可小于点击区域 |

控件正常、悬停、焦点、按下、禁用、忙碌、错误状态均须定义。禁用与忙碌采用真实状态；忙碌按钮保留原宽度并显示动作进度。表单缺少条件时在相关字段旁说明原因。

同一局部操作组最多一个实心主按钮；“保存修改”与“确认并继续”同在时，前者为次按钮，后者为主按钮。侧栏“新建任务”是固定全局动作，可与内容主操作同时存在。

### 6.2 图标

- 产品自行选择的操作图标统一使用 **Tabler Outline**，16 / 20 / 24px 三档，默认 stroke=2，保持原始 viewBox 和 path。
- 明确映射：设置 `IconSettings`；浅色 `IconSun`；深色 `IconMoon`；跟随系统 `IconSunMoon`；反馈 `IconMessageReport`；GitHub `IconBrandGithub`。
- 框架组件内部图标允许随原生组件保留；同一操作条内统一尺寸、颜色和视觉粗细。
- 媒体控件采用 Tabler 原版实心播放/暂停字形。
- 有填充需求时选择对应的原版实心图标。禁止对带外圈的线性图标整体 `fill-current`；播放三角和暂停双竖线必须清晰可辨。
- 可操作图标默认同色。按钮、菜单触发器、外链的差别由行为和辅助标签表达，避免通过无意义的深浅差别暗示禁用。
- 纯图标按钮必须有可访问名称与悬停提示；点击区域按控件标准设置。

### 6.3 导航与主题

- 侧栏顺序保持：工作台、任务库、工作流、资源、扩展；底部：设置、主题、反馈、GitHub，左对齐。
- 当前导航项采用轻背景 + 粉蓝细标记 + 当前页语义；不为每项分配不同颜色。
- 主题是三选一菜单：**浅色 → 深色 → 跟随系统**。首次默认浅色，后续尊重已保存选择。
- 主题触发图标表示当前偏好；跟随系统始终显示 `IconSunMoon`，菜单用勾选标识选中项。
- 系统标题栏空间由外壳管理；主内容不重复预留顶部空带。macOS 折叠侧栏时保留真实窗口按钮避让。

### 6.4 输入、选择与编辑

- 标签说明内容，placeholder 提供简短示例；必要信息不能仅依赖 placeholder。
- 文本、选择、时间范围控件遵循同一边框与高度。时间范围用“开始 — 结束 s”，避免重复堆叠标签。
- 输入错误展示在字段附近，保留用户输入，聚焦可修改位置。
- 多行编辑随内容增高；宽屏原文与译文等宽，顶端对齐。
- 只读值使用正文或明确只读字段，保留复制能力；避免用禁用态低对比显示结果。

### 6.5 进度、状态、日志

- 分开表达：等待、准备中、下载中、安装中、校验中、可用、失败。下载完成后继续显示校验阶段。
- 有总字节数时显示真实进度、已下载 / 总量、速度；未知总量时显示当前阶段与已用时间，不伪造百分比。
- 长任务默认展示最新活动与距上次输出时间。无输出时如实显示“距上次输出 …”，不能据此直接断言卡死。
- 底部提供可展开日志，含阶段、时间与错误；用户向上阅读后不强行滚动到末尾。
- 切换下载源时保留失败原因与新的来源；失败不能显示成功颜色。
- 错误提示包含发生了什么、具体原因、可执行恢复动作。技术明细放入日志。

### 6.6 媒体

- 视频按源比例 contain，剩余区域黑底；不裁剪字幕或内容来填满容器。
- 暂停时可显示中央播放；播放后收起遮挡。控制条播放按钮与实际 paused 状态同步。
- 悬停和键盘焦点均可显示控制条；进度、音量、全屏操作有可访问标签。
- 白色图标叠加深色控制条渐层，逐帧检查可读性。播放进度可使用品牌渐变。
- 音频优先复用现有原生控件；同组播放器同宽、同高、同基线。

## 7. 页面模板

| 页面 | 推荐结构 | 必须保持的对齐关系 |
| --- | --- | --- |
| 工作台 | 品牌入口 → 一个主输入组 → 条件/资源状态 | 链接与上传区同宽；选项与主按钮同一底栏 |
| 任务库 / 资源 | 标题与操作 → 筛选 → 连续列表 | 名称、状态、动作列跨行对齐 |
| 任务详情 | 面包屑/标题/状态 → 媒体 → 生成文件 → 工作流 | 媒体与文件组共享内容宽度 |
| 节点详情 | 返回 → 标题/状态 → 结果/输入/配置/日志 → 内容 → 操作条 | 版本只放结果页；底栏紧凑，不新增大白卡 |
| 语音校对 | 音频 → 搜索 → 序号 / 时间范围 / 文本列表 | 宽屏一行结构；文本自然换行 |
| 翻译校对 | 搜索 → 共享原文/译文表头 → 两列内容 | 序号独立，原文与译文顶端对齐 |
| 设置 | 分类 → 字段组 → 局部保存/验证 | 标签列与控件列稳定；说明仅在必要处 |
| 环境准备 | 阶段 → 资源行 → 总体状态 → 可展开日志 | 名称、下载状态和动作位置稳定 |
| 工作流画布 | 紧凑标题栏 → 工具栏 → 可缩放画布 | 画布占剩余空间，节点端口与连接线语义一致 |

普通阅读与设置页沿用现有 1152px 最大容器宽度；媒体与复杂编辑页可随可用空间扩展。工作流画布不套阅读页最大宽度。禁止在页面内部再次绘制侧栏或窗口标题栏。

## 8. 响应式、动效与文案

以**主内容容器宽度**决定布局，避免仅用整个窗口宽度推断可用空间：

- ≥960px：时间范围与正文并排；翻译双列；工具栏单行优先。
- 640–959px：空间不足的元数据换行；保留双列阅读需保证每列至少约 240px。
- <640px：原文/译文上下排列并显示各自标签；操作条可换行，触屏目标 44px；页面无水平溢出。
- 断点是布局切换基线；长文件名、多语言和侧栏展开后的实际内容宽度也必须验证。

动效标准：悬停/焦点 150ms，菜单与折叠 150–200ms；位移不超过 8px。移除持续装饰动画对编辑区的干扰。减少动态效果模式下关闭非必要位移、漂浮、闪光。

文案使用“动作 + 对象”：保存修改、下载字幕、重新检查、确认并继续。状态使用已完成、待确认、下载中等短语。错误说明保留具体原因；页面不添加功能介绍、通用提示和重复标题。

## 9. 实施边界与收敛清单

**本次交付定义设计标准，不修改应用运行时。** 保留现有架构；在已有主题、样式与适配层收敛，避免新增一套独立组件库。

| 优先级 | 现状 / 风险 | 落点与验收 |
| --- | --- | --- |
| P0 | 品牌红小字、浅灰占位、品牌蓝功能图标对比不足 | 主题功能色；实测明暗色及叠加背景 |
| P1 | Web 与桌面控件几何存在多套来源 | 直接复用 Harness 原组件；适配层仅转换业务参数和布局 |
| P1 | 普通 Web ThemeToggle 仍是二态，桌面是三选一 | 若 Web 继续作为支持入口，同步主题行为和默认值 |
| P1 | 业务图标混用 Tabler / Lucide / 框架别名 | 新增图标采用 Tabler；既有控件分组收敛并检查播放填充 |
| P1 | 部分页面仍用窗口媒体查询判断内容宽度 | 按实际主容器检查侧栏展开、折叠与窄屏 |
| P2 | 卡片层级、渐变边框、浮层阴影使用范围较宽 | 同组连续列表，浮层才使用强阴影 |
| P2 | CSS 深色主题注释仍标“默认” | 实现变更时同步注释，产品默认固定浅色 |

已在当前代码观察到的可沿用模式：底部四图标同色左对齐、桌面主题三选一、字幕/翻译连续列表、紧凑节点操作条、独立播放/暂停字形。其他页面必须单独验证，不能由这些组件推断全局已达标。

### 单页验收标准

- 明暗主题、空态、正常、忙碌、失败、禁用和焦点状态均有明确表现。
- 同组左右边缘、表头与行、输入与选择框高度一致；长文本自然换行。
- 检查主容器 375 / 768 / 1152px 及系统文字放大；工作流允许画布平移，普通页面无水平溢出。
- 键盘可抵达并操作控件；焦点可见；纯图标有名称；状态不只靠颜色。
- 真实媒体播放、暂停、定位与图标状态一致；真实下载进度和日志来源可核对。
- 每条辅助文案均能帮助识别内容、理解约束或完成动作；删除无用说明。
- 桌面通过实际 Harness 适配后的界面验收；浏览器组件截图单独标注，不代替原生验收。

规范变更集中更新本文与速查页，并记录涉及的语义 token 或页面模式。新需求先复用这里的规则，存在具体内容或交互限制时再增加例外。
