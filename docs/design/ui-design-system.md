# YouDub UI 设计规范 v2.2

2026-10-23 · 适用：桌面应用、业务页面、插件提供的产品界面。

**控件、主题颜色与交互的权威规范：** [Harness × YouDub 视觉与组件规范](harness-visual-spec.md)。下文保留品牌体系与业务页面准则；发生冲突时控件采用上述同源规范。

本规范从现有 Logo、主题代码、桌面外壳及工作台、任务、字幕校对、播放器、环境准备截图提取。**现有基线** 表示当前资产或实现；**统一标准** 表示后续设计与开发执行的规则。规范完成不代表全产品已完成视觉整改。

在仓库根运行 `node scripts/build-ui-design-reference.mjs`，打开生成的 `output/ui-design-reference.html` 查看明暗主题示例。生成页不连接真实任务，不重复提交已存在于源码中的 CSS。

## 1. 品牌定位与视觉性格

**品牌定义：亲和、清晰、可掌控的视频语言工作台。**

| 特征 | 视觉表达 | 行为表达 |
| --- | --- | --- |
| 视频与声音 | 现有播放气泡、左右声波、媒体画面 | 播放、定位、试听和导出入口清楚 |
| 轻盈与亲和 | 柔和圆角、低饱和底色、少量粉蓝渐变 | 用具体动作命名，减少技术术语 |
| 专注与专业 | 字幕对齐、稳定栅格、紧凑列表 | 优先呈现内容、结果与必要参数 |
| 可掌控 | 状态标签、真实进度、清晰的当前项 | 错误可见，修改可保存，日志可展开 |

品牌色保留在 Logo、字标、入口背景渐变和主操作按钮。主按钮采用 YouDub 红色 #e6002e、悬停 #cc0029、白字；选中态、状态提示和大面积底色采用 Harness 原生主题。视频、字幕和音频结果拥有最高内容优先级。

现有“让视频说另一种语言”保留为工作台入口的品牌表达；任务、设置、资源、日志页面不重复口号。品牌氛围光只用于入口区域，内容编辑区保持平静背景。

## 2. Logo 与品牌资产

**现有基线：** 红色播放气泡，左侧粉色声波，右侧蓝色声波；字标沿用现有 YouDub 资产与粉蓝渐变。[资产](../../apps/web/public/youdub-logo.svg) · [图形标](../../apps/web/public/youdub-icon.svg) · [品牌组件](../../apps/web/src/components/brand/brand-mark.tsx)。

统一标准：

- 使用原 SVG 等比缩放；完整字标与独立图形标分别用于宽侧栏和紧凑入口。
- 品牌垂直对齐以播放方形主体、声波和字标的共同中线为准。SVG 以 y=150 为中线，画布范围为 -56 至 356；上方留白平衡底部气泡尖角。静态资产和动画组件使用同一坐标基准，布局不额外补偏移。
- Logo 四周留白至少为其显示高度的 1/4；高度按容器确定，侧栏完整品牌画布高 32px，紧凑图形标宽 32px。品牌区位于侧栏自己的窗口控制区下方，展开时上下内边距各 16px；macOS 收起时整列隐藏，展开与新建入口回到顶部横栏。
- 使用原资产中的字形；不以普通字体重新拼写字标，不修改三角、声波和气泡比例。
- 粉→蓝渐变方向固定为从左向右；导航选中态使用 Harness 原生表面色。
- 工作台主视觉按可见红色矩形高度确定尺寸：与主标题字号 `clamp(28px,4vw,48px)` 相同；SVG 总高按 `主体高度 × 412 / 300` 计算，计入尾尖和光学留白，禁止因 viewBox 扩大而缩小可见图形。Logo 与标题保持 24px 间距。
- **Logo 声波动效必须保留。** 侧栏（显示时）、工作台、首次准备与翻译配置的品牌入口统一使用 `BrandMark animated`，默认持续播放。左右声波沿用现有 1.1 秒错峰起伏，中央气泡与字标保持稳定；不得在 Harness 样式统一中删除或换成静态图。系统减少动态效果时展示静态 Logo。完整规则与验收项见[Harness × YouDub 规范第5节](harness-visual-spec.md#5-动效与焦点)。
- 窗口系统指示器、鼠标高亮和截图标注不属于 YouDub 品牌资产。

## 3. 颜色与语义

### 3.1 品牌原色：保留

| Token | 值 | 使用范围 |
| --- | --- | --- |
| `brand-red` | `#FF0033` | Logo、品牌图形、装饰性强调 |
| `brand-pink` | `#FB7299` | 声波、渐变起点 |
| `brand-blue` | `#00AEEC` | 声波、渐变终点 |

渐变遵循 `brand-pink → brand-blue`。不把渐变作为长段文字、输入内容、错误信息的填色。

### 3.2 浅色与深色：Harness 原生主题

配色权威为 [Harness design-platform.css](../../vendor/deepseek-harness/source/packages/client/ui-theme/src/styles/design-platform.css)。业务 token 通过 [共享配色桥接](../../apps/web/src/app/harness-palette.css) 单向引用 Harness token；Web 与桌面共用该文件，禁止以旧 YouDub 调色板覆盖 `--dsw-*`。

| 业务语义 | Harness token |
| --- | --- |
| 页面底色 | `--dsw-alias-bg-base` |
| 侧栏 | `--dsw-specific-sidebar-fill`，保留原生平台材质 |
| 内容 / 浮层 | `--dsw-alias-bg-layer-1` / `bg-layer-2` |
| 正文 / 辅助文字 | `--dsw-alias-label-primary` / `label-secondary` |
| 分隔 / 输入边线 | `--dsw-alias-border-l2` / `border-l4` |
| 主操作 / 悬停 / 文字 | `--dsw-alias-button-primary-fill` / `button-primary-hover` / `label-primary-foreground` |
| 链接、焦点、运行态 | `--dsw-alias-link` / `state-business-primary` |
| 完成 / 警告 / 错误 | `--dsw-alias-state-success-primary` / `state-warn-label` / `state-error-primary` |

主题切换由 Harness 控制浅色、深色及跟随系统。浅深色的主按钮均保留 YouDub 红色与白字；状态须同时提供明确标签或图标。

### 3.3 背景渐变：保留品牌氛围，以 Harness 底色承载

- 工作台及既有品牌入口保留红、粉、蓝背景渐变与 Logo 动效；渐变范围沿用既有入口布局。
- 渐变叠加在当前主题的 `--dsw-alias-bg-base` 上，边缘淡出至透明，露出 Harness 底色。禁止使用旧浅灰、旧黑色背景或独立固定底色。
- 渐变沿用共享 `aurora`；浅色强度 0.55、深色 1，两种主题分别截图确认。页面正文、按钮、选中态和浮层继续使用 Harness 语义颜色。
- 内容编辑区、设置、资源列表保持 Harness 平静表面；渐变不降低输入内容、错误原因及操作的可读性。

### 3.4 可读性依据

按 [W3C 文本对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)，普通文本采用至少 4.5:1，大文字至少 3:1；必要控件标识和状态指示采用至少 3:1，见 [W3C 非文本对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。轻分隔线可保持低对比，关键识别信息须由可读文字、图标或足够清晰的轮廓承担。

验收以运行中的浅色、深色截图为准，同时检查渐变叠加后的实际对比度。旧 YouDub 调色板的对比度数据不作为当前配色的验收证据。

## 4. 字体、排版与数字

界面沿用系统无衬线字体。中文优先系统中文字体，英文与数字使用系统 UI 字体。日志使用系统等宽字体；时间、大小、速度使用等宽数字 `tabular-nums`，不把整个表单改成等宽字。

| 层级 | 字号 / 行高 | 字重 | 应用 |
| --- | --- | --- | --- |
| 品牌展示 | `clamp(28px, 4vw, 48px)` / 1.2 | 700 | 工作台现有品牌标题，限入口 |
| 页面标题 | 20 / 28px | 500 | 任务、资源、设置、节点标题 |
| 分组标题 | 16 / 24px | 600 | 生成文件、输入参数 |
| 业务正文 | 14 / 20px | 400 / 500 | 字幕、译文、表单内容 |
| 标准控件 | 继承 Harness 原组件 | 继承原组件 | Button、Input 为 14 / 22px；其他控件见同源规范 |
| 辅助信息 | 12 / 18px | 400 | 单位、时间、格式、版本 |
| 日志 | 12 / 18px | 400 | 保留换行，长行可折行 |

正文不使用 300 细字。14px 正文优先保证行距；长字幕自然换行，不以固定高度截断可编辑内容。独立移动浏览器入口若发生聚焦放大，在该承载端验证并调整；桌面窄窗口保持 Harness 控件字阶。

## 5. 间距、圆角与层次

### 5.1 间距系统

YouDub 业务排列采用 **4px 基础刻度、8px 主节奏**。页面及控件直接复用 Harness 的既有尺寸，包括 6px、20px、28px；业务间距规则不覆盖组件内部几何。

| 关系 | 标准 |
| --- | --- |
| 图标与短文字 | 8px；紧凑控件 4px |
| 标签到输入框 | 8px |
| 同组操作间距 | 8px |
| 列表行内边距 | 12px |
| 普通卡片内边距 | 16px |
| 对话框内边距 | 继承 Harness Modal：内容 20px、侧边 24px |
| 主输入组内边距 | 24px；窄屏 16px |
| 同页内容组间距 | 共享 Page 的 32px |
| 页面内容边距 | 顶部 28px；横向 clamp(24px, 4vw, 48px) |
| 普通页面内容宽度 | 960px，加共享容器横向内距 |
| 首次准备表单内容宽度 | `Page width="form"`：沿用 Harness ModelsSection 的 720px 上限，加共享横向内距 |

输入框和上传区域的默认边界保持轻盈，避免深灰描边与大面积灰色填充叠加；聚焦、拖入和错误状态才增强边界。品牌标题、背景氛围和整体布局保留。

宽度由共同父容器和栅格决定。同组视频链接框与上传区左右边缘完全一致。表头、列表行、底部操作共享内容边界。避免单个控件额外加 padding 修补截图对齐。

共享 Page 通过纵向布局的 gap 维持内容组间距。Harness 插槽使用 `display: contents` 包装时，间距仍应作用于实际内容盒；不依赖直接子元素的相邻 margin 选择器。承载结果编辑器等插槽的局部分组沿用同一布局方式，并采用对应的组内间距。

安装目录、环境准备、模型准备、服务配置及其加载/失败状态统一使用 `SetupPage`，复用 `Page width="form"`。品牌、正文和页尾共用内容边界，不再叠加 border-box 的 `max-w-3xl`；页头按内容换行。品牌与内容组之间使用 32px gap，阶段标题/反馈/操作之间 24px，日志与资源列表之间 16px；组间距由父布局负责，卡片不携带外边距。模型标题与配置卡片沿用 Harness 的 12px 组内间距，页尾按钮间距为 8px；空的已配置模型列表不占布局空间。

资源行按名称的内容宽度分配空间，状态与操作作为一组换行；窄窗口下不强迫资源名称逐字折行。分段控件受父容器宽度约束，长标签可以换行，单行仍保持 Harness 原有高度。

桌面区域分工遵循 [Harness 区域职责](harness-visual-spec.md#11-桌面区域职责2026-10-23)：窗口控制、全局导航、当前页面操作、内容工具和工作内容分别归位。侧栏直接复用 SidebarRoot，选中态采用原组件表面，不再添加渐变竖条。

### 5.2 圆角：收敛到四档

| 目标 Token | 值 | 应用 |
| --- | --- | --- |
| `radius-control` | Harness `radius-md`（12px） | 按钮、输入框；紧凑按钮和多行编辑器使用 `radius-sm`（8px） |
| `radius-panel` | Harness `radius-lg`（16px） | 内容组；菜单直接复用 Harness Menu 的圆角 |
| `radius-dialog` | Harness `radius-panel`（28px） | 对话框直接复用 Harness Modal |
| `radius-pill` | 999px | 状态标签、轨道滑块 |

Harness 已有的基础控件直接使用其组件、尺寸、圆角和状态样式。YouDub 只负责布局与品牌主题映射，页面不另写控件外观；品牌主按钮仅通过共享主题 token 配置颜色。相同功能使用同一组件；多行表单复用 Harness 编辑器样式并保留原有保存语义。

### 5.3 层次

- 页面 → 内容组 → 行。列表用一个容器加细分隔，行内不继续套卡片。
- 卡片默认依赖底色与轻边框；普通列表和底部操作条不加浮层阴影。
- 菜单、弹窗直接复用 Harness 的阴影和层级，不叠加 YouDub 阴影。
- 单个内容组避免同时叠加强边框、渐变描边、厚阴影和玻璃效果。
- 玻璃材质限桌面外壳与悬浮操作；编辑正文保持稳定底色。

## 6. 组件与交互

组件入口与逐页复用结果见[组件源码索引](component-inventory.md#2026-10-24-客户端复用审查)。所有被动进度显示直接引用 `Progress`；资源行引用 `ResourceRow`。普通表面使用 `Surface`，卡片链接使用 `surfaceVariants`，下载链接使用 `buttonVariants`，操作错误使用 `InlineAlert`。页面只设置内容排列，不复制这些组件的外观或交互逻辑。视频定位与音量滑块保留交互语义。

### 6.1 控件尺寸与状态

| 组件场景 | 高度 / 点击区域 | 图标 | 说明 |
| --- | --- | --- | --- |
| 紧凑按钮 | Harness 28px | 16px | 普通控件使用 Harness 默认档位 |
| 标准按钮 | 36px | 16px | 保存、刷新、页内动作 |
| 普通输入框 | Harness 32px | 16px | 下拉入口使用 Harness Button + Menu |
| 工作台主动作 | 44px | 20px | 开始处理 |
| 触屏交互目标 | 至少 44×44px | 20px | 图标可小于点击区域 |

控件正常、悬停、焦点、按下、禁用、忙碌、错误状态均须定义。禁用与忙碌采用真实状态；忙碌按钮保留原宽度并显示动作进度。表单缺少条件时在相关字段旁说明原因。

同一局部操作组最多一个实心主按钮；“保存修改”与“确认并继续”同在时，前者为次按钮，后者为主按钮。侧栏“新建任务”是固定全局动作，可与内容主操作同时存在。

### 6.2 图标

- 产品自行选择的操作图标统一使用 **Tabler Outline**，16 / 20 / 24px 三档，默认 stroke=2，保持原始 viewBox 和 path。
- 明确映射：设置 `IconSettings`；浅色 `IconSun`；深色 `IconMoon`；跟随系统 `IconSunMoon`；反馈 `IconMessageReport`；GitHub `IconBrandGithub`。
- 框架组件内部图标允许随原生组件保留；同一操作条内统一尺寸、颜色和视觉粗细。
- 媒体控件采用 Tabler 原版实心播放/暂停字形。
- 有填充需求时选择对应的原版实心图标。禁止对带外圈的线性图标整体 `fill-current`；播放三角和暂停双竖线必须清晰可辨。
- 可操作图标默认同色。按钮、菜单触发器、外链的差别由行为和辅助标签表达，避免通过无意义的深浅差别暗示禁用。
- 纯图标按钮必须有可访问名称与悬停提示；点击区域按控件标准设置。

### 6.3 导航与主题

- 侧栏顺序保持：工作台、任务库、工作流、资源、插件；底部：设置、主题、反馈、GitHub，左对齐。
- 当前导航项使用 Harness SidebarRoot 的原生选中背景与当前页语义；不添加品牌色标记或给每项分配颜色。
- 主题是三选一菜单：**浅色 → 深色 → 跟随系统**。首次默认浅色，后续尊重已保存选择。
- 主题触发图标表示当前偏好；跟随系统始终显示 `IconSunMoon`，菜单用勾选标识选中项。
- 系统标题栏空间由外壳管理；主内容不重复预留顶部空带。macOS 折叠侧栏时保留真实窗口按钮避让。

### 6.4 输入、选择与编辑

- 标签说明内容，placeholder 提供简短示例；必要信息不能仅依赖 placeholder。
- 文本、选择、时间范围控件遵循同一边框与高度。时间范围用“开始 — 结束 s”，避免重复堆叠标签。
- 输入错误展示在字段附近，保留用户输入，聚焦可修改位置。
- 添加模型提供商时先显示未选择状态，用户选择后才显示对应字段与认证提示。目录刷新及添加方式切换保留已选提供商和草稿，不依据目录顺序代选。首次翻译配置的“稍后配置”和“继续”同样经过共享编辑器的离开保护；用户确认放弃前不丢弃草稿，保存中不能离开。
- 多行编辑随内容增高；宽屏原文与译文等宽，顶端对齐。
- 只读值使用正文或明确只读字段，保留复制能力；避免用禁用态低对比显示结果。纯结果查看器不显示无法使用的“保存订正”；待确认结果仍保留确认继续或完成动作。

### 6.5 进度、状态、日志

- 分开表达：等待、准备中、下载中、安装中、校验中、可用、失败。下载完成后继续显示校验阶段。
- 首次准备按环境、模型两个阶段依次显示；标题、实时日志和资源列表只显示当前阶段，环境完成后进入模型准备。
- 进行中的进度条使用从左到右的 `brand-pink → brand-blue` 渐变；完成和暂停继续使用成功、暂停语义色，轨道沿用 Harness 表面色。
- 工作流摘要同时反映未配置服务和未就绪资源；详细缺项按需展开。摘要精简不改变资源准备或运行门槛。
- 有总字节数时显示真实进度、已下载 / 总量、速度；未知总量时显示当前阶段与已用时间，不伪造百分比。
- 长任务默认展示当前资源、阶段、真实进度、已用时间与距上次输出时间。实时日志按时间顺序展示 uv／pip 的逐包输出和文件下载字节进度，记录阶段完成；完整诊断仍可展开。无输出时如实显示“距上次输出 …”，不能据此直接断言卡死。
- 等待用户确认准备时使用等待状态；环境标题仅在步骤实际运行时显示忙碌动效，未就绪本身不等于正在运行。
- 日志视口以 6–12 行为上下限，按窗口高度的 1/4 分配可读区域，内边距沿用共享刻度；不按窗口宽度切换固定高度，也不随日志条数增高。“回到最新日志”预留控件位置；跟随模式在窗口缩放后仍停在末尾，用户向上阅读后不强行滚动。
- 切换下载源时保留失败原因与新的来源；失败不能显示成功颜色。
- 错误提示包含发生了什么、具体原因、可执行恢复动作。技术明细放入日志。

### 6.6 媒体

- 视频按源比例 contain，剩余区域黑底；不裁剪字幕或内容来填满容器。
- 暂停时可显示中央播放；播放后收起遮挡。控制条播放按钮与实际 paused 状态同步。
- 悬停和键盘焦点均可显示控制条；进度、音量、全屏操作有可访问标签。
- 白色图标叠加深色控制条渐层，逐帧检查可读性。播放进度可使用品牌渐变。
- 音频优先复用现有原生控件；同组播放器同宽、同高、同基线。
- 全屏媒体采用深色背景时，语言选项、进度与音量控件同步使用深色语义色，保证应用浅色主题下仍可读。

## 7. 页面模板

| 页面 | 推荐结构 | 必须保持的对齐关系 |
| --- | --- | --- |
| 工作台 | 品牌入口 → 一个主输入组 → 条件/资源状态 | 链接与上传区同宽；选项与主按钮同一底栏 |
| 任务库 / 资源 | 标题与操作 → 筛选 → 连续列表 | 名称、状态、动作列跨行对齐 |
| 任务详情 | 面包屑/标题/状态 → 媒体 → 生成文件 → 工作流 | 媒体与文件组共享内容宽度 |
| 节点详情 | 返回 → 标题/状态 → 结果/输入/配置/日志 → 内容 → 操作条 | 版本只放结果页；底栏紧凑，不新增大白卡 |
| 语音校对 | 音频 → 搜索 → 序号 / 时间范围 / 文本列表 | 宽屏一行结构；文本自然换行 |
| 翻译校对 | 搜索 → 共享原文/译文表头 → 两列内容 | 序号独立，原文与译文顶端对齐 |
| 设置 | 分类 → 字段组 → 局部保存/验证 | 标签列与控件列稳定；说明仅在必要处 |
| 环境准备 | 阶段 → 资源行 → 总体状态 → 可展开日志 | 名称、下载状态和动作位置稳定 |
| 工作流画布 | 紧凑标题栏 → 工具栏 → 可缩放画布 | 画布占剩余空间，节点端口与连接线语义一致 |

普通页面使用共享 Page 的 960px 内容宽度与自适应横向内距；设置保留 Harness 原生结构，媒体与复杂编辑页可按业务需要扩展。工作流画布不套阅读页最大宽度。禁止在页面内部再次绘制侧栏或窗口标题栏。

工作流的节点库、输入、输出和运行面板使用对应工具栏入口表达展开状态；关闭按钮和 Escape 关闭后，焦点回到对应入口。子菜单优先处理自身的 Escape，提交锁定时保留面板。校验错误用当前界面语言说明修复动作，原始诊断按需展开；未识别的错误原样保留。

## 8. 响应式、动效与文案

以**主内容容器宽度**决定布局，避免仅用整个窗口宽度推断可用空间：

- ≥960px：时间范围与正文并排；翻译双列；工具栏单行优先。
- 640–959px：空间不足的元数据换行；保留双列阅读需保证每列至少约 240px。
- <640px：原文/译文上下排列并显示各自标签；操作条可换行，触屏目标 44px；页面无水平溢出。
- 断点是布局切换基线；长文件名、多语言和侧栏展开后的实际内容宽度也必须验证。
- 工作台参数区按输入容器可用宽度换行；参数和主操作无法舒适并排时，主操作排在全部参数之后。不能让按钮悬在多行参数中间。

交互动效沿用[Harness × YouDub 规范第5节](harness-visual-spec.md#5-动效与焦点)的组件时序。品牌入口必须保留 Logo 声波循环；编辑内容区避免持续装饰动画。减少动态效果模式下关闭非必要位移、漂浮、闪光，并将 Logo 展示为静态。

桌面构建的动画工具类带有 `!important`；减少动态效果规则放在保留的 `components` 层，以重要声明的层顺序覆盖 `utilities`。禁止将该规则移入桌面会移除的 `base` 层。验收须切换实际系统偏好，比较 Logo 连续截图，不能只检查存在媒体查询。

文案使用“动作 + 对象”：保存修改、下载字幕、重新检查、确认并继续。状态使用已完成、待确认、下载中等短语。错误说明保留具体原因；页面不添加功能介绍、通用提示和重复标题。

资源准备失败时，资源行展示原始错误的首行原因，子进程路径前缀放入诊断详情。摘要最多三行；完整原文通过同一行的 Harness 折叠控件展开，可聚焦并滚动阅读，避免长错误挤走重试和后续资源。复制日志仍保留完整诊断。

语言参数明确标注原文、译文、配音或导出语言，避免仅写“目标”造成目的地与语言混淆；快捷参数的无障碍名称与可见标签一致，同名节点需要区分时保留节点名称和编号。各节点的参数仍按实际业务语义独立保存。空列表或仅有一页时隐藏无用分页；当前位于后续页时，即使该页变空也保留返回上一页的入口，并使用“本页没有任务”区分分页空态与整个任务库为空。安装目录校验失败时保留表单与路径，在字段附近显示原始错误并聚焦输入；目录选择器确定或取消后，焦点返回选择入口。连接读取失败仍显示连接诊断和重试入口。

### 单页验收标准

- 明暗主题、空态、正常、忙碌、失败、禁用和焦点状态均有明确表现。
- 同组左右边缘、表头与行对齐；同类控件高度一致，不同原生控件保留契约尺寸；长文本自然换行。
- 检查主容器 375 / 768 / 1152px 及系统文字放大；工作流允许画布平移，普通页面无水平溢出。
- 键盘可抵达并操作控件；焦点可见；纯图标有名称；状态不只靠颜色。
- 真实媒体播放、暂停、定位与图标状态一致；真实下载进度和日志来源可核对。
- 每条辅助文案均能帮助识别内容、理解约束或完成动作；删除无用说明。
- 桌面通过实际 Harness 适配后的界面验收；浏览器组件截图单独标注，不代替原生验收。

### 插件页面一致性（2026-10-23）

导航、页头和返回入口统一称“插件”。页头的说明按钮与标题同排，未提供简介时不保留空简介行。内置插件的版本与来源复用 Harness 插件详情的事实行样式，保持标签和值的间隔、边界及换行规则。依据为窄窗口原生检查中出现的孤立说明图标和紧贴的版本标签；适用于插件列表及内置功能详情。

### 任务执行图状态（2026-10-23）

节点完成或进入人工确认后，卡片省略历史过程消息，避免“已完成 / 待确认”与“正在处理”并列；运行、等待和失败信息保持可见。缺少节点插件时仍使用任务已保存的可读名称，保留缺失提示；同一输出连接多个下游时只显示一个端口。实际任务记录、依赖边和执行策略保持原语义。
