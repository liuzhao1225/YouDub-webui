01

品牌语言

亲和

柔和圆角与粉蓝品牌色。
让入口轻松，减少界面压力。

清晰

中性背景与稳定的对齐。
让视频、字幕和结果居于中心。

可掌控

真实进度与明确的动作。
让用户知道当前状态和下一步。

07

设计边界

保留并统一

  • 原版 Logo 与粉蓝渐变方向
  • Tabler 原版操作图标
  • 同组控件的尺寸、颜色和边界
  • 真实状态、进度与可展开日志

收敛与检查

  • 低对比小字和功能图标
  • 重复卡片、粗分隔和过重阴影
  • 桌面与业务控件的几何差异
  • 长文本、多语言和窄屏布局
