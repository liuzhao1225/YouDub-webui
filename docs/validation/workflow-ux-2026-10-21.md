# 工作流体验与节点确认验收

本轮在 `codex/workflow-nodes` 分支完成。验收使用本地生产前端、真实 Host 和 SQLite；人工确认流程使用仓库内的文本插件，不调用外部 LLM 或模型。

## 节点确认

验收图包含两段输入、两路人工校对、两路自动导出、人工汇总校对和自动汇总导出，共 8 个节点。

1. 两路校对同时进入待确认，各自显示「确认结果」。
2. 在左路专属页面订正为「左路确认后的文本」，点击「保存并继续」。左路自动导出完成，右路保留待确认，汇总未开始。
3. 确认右路后，右路导出完成，汇总进入新的待确认状态；汇总内容包含左路订正。
4. 确认汇总后，8 个节点完成，生成左路、右路、汇总三个文本文件；逐字读取并断言文件内容正确。

这次使用独立数据目录及端口，未修改现有演示任务。多个待确认节点经过 Host 重启后仍保留。执行器仍逐个调用节点，人工确认只阻塞依赖该结果的路径。

运行回归另覆盖：无关分支进度更新后仍可确认、两路同时提交确认、执行槽交接期间确认、异步等待期间订正与取消、末节点确认、确认幂等与同节点版本冲突。复用计算结果时，所有上游确认仍须通过；已复用的中间节点不能绕过新增的上游确认点。

## 页面与操作

- 工作台：收紧首屏，显示节点待确认数量，保留任务进度入口。
- 工作流库：分别提供「使用」和「编辑」，模板仅保留一个「保存副本」动作。
- 编辑器：浏览、缩放、进入节点后返回不产生离开确认；真正修改可撤销，撤销历史跨节点页面保留。首次画布保证可读缩放，手动「适应画布」可查看全图。
- 运行与重新运行：自动检查所需资源，用户主动下载；缺少配置和模型时标明节点及处理入口，原始诊断可展开查看。提交结果未知时保留本次请求，阻止重复创建。
- 任务页：生成文件在前，步骤列表与日志默认收起；节点分别显示未开始、运行、待确认和完成状态。
- 节点页：识别、翻译使用紧凑逐句布局；配音按句子 ID 对应译文、试听和下载，历史音频不误配当前译文。只读内容可选择复制。版本冲突保留未提交订正，用户明确放弃后才刷新。
- 视口：实际检查默认桌面视口与 390 × 844 窄屏；测试完成后恢复默认尺寸。
