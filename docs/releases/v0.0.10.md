本版修复 Windows 安装与模型配置问题，并完成面向 YouDub 功能范围的框架精简。

- 修复 Windows 安装版首次启动和覆盖升级问题，独立 YouDub 的启动入口、配置目录及应用身份。
- 修复 Web 首次配置模型后无法继续的问题，工作流默认自动选择可用计算设备。
- 翻译统一通过 Harness 模型服务调用，遵循提供商协议和模型参数，支持 Anthropic Messages，移除额外的 65,535 输出 token 门槛，并修正误导性的“OpenAI compatible”提示。
- 精简无用框架功能、重复实现与测试代码，保留字幕、配音、工作流、人工校对、插件和历史任务兼容。
- 改善环境准备日志、任务文件预览与界面组件一致性，将示例试听移至官网。

升级前退出 YouDub，保留原有数据目录。Windows EXE 支持覆盖 v0.0.9 安装；环境和模型仍在独立数据目录中按需准备。
