YouDub Desktop 现使用 Harness 的 Electron 外壳、侧栏、主题、设置与插件运行时，保留 YouDub 的红色操作按钮、品牌渐变、视频工作流和字幕配音界面。

- 调整窗口分区、侧栏完全收起与展开、Logo 视觉对齐和大小。
- 统一模型供应商配置，改善首启资源准备、任务节点确认、订正版本与产物预览。
- 安装包自带 Electron、Harness Host 与 pnpm，首次运行按需准备独立 Python 和媒体依赖。包含三组离线中英文示例。

macOS Apple Silicon：最低 macOS 14，DMG 已完成 Developer ID 签名、Apple 公证及 Gatekeeper 校验。

Windows x64：Windows 10 22H2 / Windows 11，提供 EXE 安装包和 ZIP 便携包，已验证独立程序的首启、页面渲染、示例读取与正常退出。内置 Electron，无需单独安装 WebView2；尚无 Authenticode 签名。

本版更换了桌面运行时。旧版数据保留原位，新版首次启动需要选择数据目录并重新确认供应商和模型配置。不要让新旧版本同时打开同一数据目录。全新机器的模型下载和真实媒体处理仍取决于选定资源、网络与模型配置；安装包首启检查不代表这些资源已准备完毕。
