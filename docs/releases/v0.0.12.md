本版修复 Windows 首次启动失败，以及部分英文视频语音识别完成后报错的问题。

- 修复 [#187](https://github.com/liuzhao1225/YouDub-webui/issues/187)、[#188](https://github.com/liuzhao1225/YouDub-webui/issues/188) 的 `EPERM: operation not permitted, symlink`：Windows 首次启动和安装路径更新使用无需管理员权限或开发者模式的目录联接。EXE 安装版和 ZIP 便携版共用此修复，保留原有任务、设置和插件配置。
- 修复 [#184](https://github.com/liuzhao1225/YouDub-webui/issues/184) 的英文识别失败：保留 Whisper 原始片段、文本和词时间戳，移除额外英文分句及 ASR 适配层的重复语义校验。
- Whisper 不再要求安装 NLTK 英文分句资源。已使用反馈中的完整英文访谈验证，509 个片段和 7,033 个词的文本、分段和时间戳全部保留。

升级前退出 YouDub，保留原有数据目录。
