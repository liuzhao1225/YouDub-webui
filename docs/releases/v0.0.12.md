本版修复 [Issue #188](https://github.com/liuzhao1225/YouDub-webui/issues/188) 中 Windows 启动时报 `EPERM: operation not permitted, symlink` 的问题。

- 首次启动和安装路径更新使用无需管理员权限或开发者模式的目录联接。
- EXE 安装版和 ZIP 便携版共用此修复，保留原有任务、设置和插件配置。

升级前退出 YouDub，保留原有数据目录。

macOS 最低版本为 14，正式 DMG 经 Developer ID 签名与 Apple 公证。Windows 安装包尚无 Authenticode 签名。每个文件附有 `.sha256` 校验文件。
