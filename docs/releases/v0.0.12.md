本版修复 [Issue #187](https://github.com/liuzhao1225/YouDub-webui/issues/187) 报告的 Windows 首次启动 `EPERM: operation not permitted, symlink` 错误。

- Windows 用户配置目录使用目录联接（junction），无需管理员权限或开启开发者模式。
- 首次启动和应用位置变化后的链接更新使用相同规则，保留已有配置和扩展。
- Windows 源码回归与安装包首启验收检查实际链接类型，防止高权限构建环境掩盖该问题。

升级前退出 YouDub，保留原有数据目录。

[macOS Apple Silicon DMG](https://github.com/liuzhao1225/YouDub-webui/releases/download/v0.0.12/YouDub-macOS-arm64.dmg) · [Windows x64 EXE](https://github.com/liuzhao1225/YouDub-webui/releases/download/v0.0.12/YouDub-windows-x64-Setup.exe) · [Windows x64 ZIP](https://github.com/liuzhao1225/YouDub-webui/releases/download/v0.0.12/YouDub-windows-x64.zip)

macOS 最低版本为 14，正式 DMG 经 Developer ID 签名与 Apple 公证。Windows 安装包尚无 Authenticode 签名。每个文件附有 `.sha256` 校验文件。
